# store — 스토어 등록 자료

구글 플레이와 애플 앱스토어에 올릴 그림과 글입니다. 앱 동작과는 무관합니다.

| 파일 | 어디에 쓰나 |
|---|---|
| `등록정보.md` | 스토어에 붙여넣을 글, 데이터 보안·콘텐츠 등급 설문 답안 |
| `앱스토어-절차.md` | 아이폰 쪽 절차와 주의할 점 |
| `icon/play-512.png` | 플레이 앱 아이콘 (512×512) |
| `icon/appstore-1024.png` | 앱스토어 앱 아이콘 (1024×1024, 투명도 없음) |
| `graphic/feature-1024x500.png` | 플레이 그래픽 이미지 |
| `screenshot/play/` | 플레이 휴대폰 스크린샷 8장 (1080×1920) |
| `screenshot/ios/` | 앱스토어 6.7인치 스크린샷 8장 (1290×2796) |

## 다시 만들기

앱 화면이 바뀌면 스크린샷도 다시 찍어야 합니다.

```
node tools/serve.js
```

다른 창에서

```
cd tools/store-assets
npm install
npm run all
```

`npm run shots` 는 앱 화면만, `npm run images` 는 아이콘·그래픽·합성만 다시 만듭니다.

## 화면 속 내용

스크린샷의 회원, 매출, 게시글은 **전부 예시**입니다 (`tools/demo-video/mock.mjs`).
실제 손님 자료가 들어가지 않도록 서버를 끊고 가짜 데이터로 찍습니다.
각 장의 아래쪽에 "화면은 예시입니다"라고 적어 두었습니다.
