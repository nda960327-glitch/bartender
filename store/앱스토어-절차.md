# 애플 앱스토어 등록 절차

먼저 알아둘 것부터. 구글 플레이보다 훨씬 까다롭고, **지금 상태 그대로 내면 거절될 가능성이 높습니다.**
이유와 해결책을 아래에 적었습니다.

---

## 0. 지금 상태의 문제 — 먼저 읽으세요

바텐톡은 웹 앱(PWA)입니다. 안드로이드는 **TWA**라는 공식 방법으로 웹 앱을 그대로 감싸
플레이에 올릴 수 있지만, **아이폰에는 그런 방법이 없습니다.**
웹 화면을 그대로 띄우는 껍데기 앱을 만들어 내면 애플 심사 규정 **4.2 (최소 기능)**에 걸립니다.

> "웹사이트를 묶어놓기만 한 앱은 승인하지 않는다. 아이폰다운 기능이 있어야 한다."

거절되면 심사자가 대개 이렇게 답합니다. "Safari로 열어도 똑같은데 왜 앱이어야 하나요?"

**해결하려면 아이폰에서만 되는 기능을 얹어야 합니다.** 예를 들면

- **애플 지갑(Wallet) 패스** — 하우스 패스를 지갑에 넣어 잠금화면에서 바로 꺼내기. 이게 가장 설득력 있습니다
- **네이티브 푸시 알림** — 빈자리 알림을 iOS 알림으로
- **네이티브 QR 스캐너** — 사장님 화면을 아이폰 카메라 API로
- **Face ID 잠금** — 패스 화면을 얼굴 인식으로 열기
- **홈 화면 위젯** — 남은 잔 수를 위젯에 표시

최소 두세 개는 있어야 안전합니다. 개발 기간이 따로 필요합니다.

### 당장 아이폰 손님을 받는 방법 (무료, 심사 없음)

아이폰 사파리에서 barapp.kr을 열고 **공유 > 홈 화면에 추가**하면
앱 아이콘이 생기고 전체 화면으로 뜹니다. iOS 16.4부터는 알림도 받습니다.
지금 당장은 이 방법을 안내하고, 앱스토어는 위 기능을 붙인 뒤에 도전하는 편이 낫습니다.

## 1. 준비물

| 항목 | 내용 |
|---|---|
| 비용 | **연 $99** (약 14만 원). 매년 냅니다. 구글은 $25 한 번이면 끝이라 차이가 큽니다 |
| 맥 컴퓨터 | **필수**. Xcode가 맥에서만 돕니다. 없으면 클라우드 맥을 빌리는 방법이 있습니다 |
| D-U-N-S 번호 | 조직으로 가입하면 필요. **플레이 때 받은 번호를 그대로 씁니다** |
| 사업자등록증 | 조직 확인용 |
| 법인/사업자 대표 확인 | 애플이 전화로 확인하는 경우가 있습니다 |

개인 자격으로 가입하면 D-U-N-S 없이 되지만, 스토어에 **사장님 본인 이름**이 뜹니다.
가게 이름으로 띄우려면 조직으로 가입해야 합니다.

## 2. 순서

**① Apple Developer Program 가입** — developer.apple.com
Apple ID 만들기 → 2단계 인증 켜기 → Enroll → 조직 선택 → D-U-N-S 입력 → $99 결제
심사에 보통 **2일 ~ 2주**. 애플이 대표 전화로 확인 전화를 걸 수 있습니다.

**② App Store Connect에 앱 만들기** — appstoreconnect.apple.com
번들 ID(예: `kr.barapp.bartalk`), 앱 이름, 기본 언어(한국어), SKU 입력

**③ iOS 앱 만들기** — Xcode
위 0번에서 고른 기능을 넣어 WKWebView 기반 앱을 만듭니다. 개발 작업이 필요한 구간입니다.

**④ 등록정보 채우기** — `등록정보.md` 의 글을 그대로 씁니다
- 아이콘: `icon/appstore-1024.png` (투명도가 없어야 합니다 — 있으면 자동 반려)
- 스크린샷: `screenshot/ios/` 의 6.7인치 8장
- 연령 등급: **17+ 이상** (주류)
- 개인정보처리방침: `https://barapp.kr/privacy.html`
- **App Review Information에 심사자용 계정** — `등록정보.md` 6번 참고. 없으면 무조건 반려입니다

**⑤ 제출 → 심사** — 보통 24~48시간, 첫 앱은 더 걸립니다

## 3. 심사에서 걸릴 만한 것

**4.2 최소 기능** — 위 0번. 가장 큰 위험입니다.

**3.1.1 앱 내 결제 강제** — 애플은 디지털 상품을 팔면 자사 결제(수수료 15~30%)를 쓰라고 합니다.
다만 **실제 매장에서 받는 물건이나 서비스는 예외**입니다 (가이드라인 3.1.3(e)).
하우스 패스는 가게에 가서 술을 받는 것이므로 예외에 해당해 토스 결제를 그대로 쓸 수 있습니다.
심사 메모에 이렇게 적어 두세요.

> 이 앱의 구독은 제휴 매장에서 현장 제공되는 음료를 위한 것으로,
> 앱 밖에서 소비되는 실물 서비스입니다 (Guideline 3.1.3(e)).

그래도 심사자가 IAP를 요구하면, 위 조항을 근거로 답변(Reply)을 보내면 대개 통과됩니다.

**주류 관련** — 음주를 부추기는 표현("무제한", "부어라 마셔라")은 쓰지 마세요.
연령 등급을 낮게 잡으면 반려됩니다.

**계정 삭제 기능** — 앱 안에서 회원 탈퇴가 가능해야 합니다. 바텐톡은 이미 있습니다.

## 4. 권하는 순서

1. **지금** — 구글 플레이부터 끝냅니다. 서류 승인 기다리는 중이니 그동안 스토어 글과 그림을 준비
2. **그다음** — 아이폰 손님에게는 "사파리에서 홈 화면에 추가"를 안내
3. **나중에** — 애플 지갑 패스와 푸시 알림을 붙인 뒤 앱스토어에 도전

순서를 이렇게 잡으면 $99를 미리 쓰지 않아도 되고, 거절당하며 시간을 버리지 않습니다.
